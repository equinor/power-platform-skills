# Code of Conduct

This repository is a fork of [microsoft/power-platform-skills][upstream_repo] and keeps the [Microsoft Open Source Code of Conduct][msoss_coc] as its standard of behaviour. What changes in this fork is **where you report a concern**: the contacts below are Microsoft's and cannot action anything in this repository.

## Reporting a concern

- **Conduct in this repository** (issues, pull requests, review comments): raise it with `@equinor/dcs-power-platform-team`. If it is not appropriate to discuss in public, use the private reporting route in [SECURITY.md](SECURITY.md) rather than opening an issue.
- **Equinor personnel**: use Equinor's internal ethics and compliance reporting channels, which take precedence over anything in this file.
- **Conduct in the upstream Microsoft repository**: report it to Microsoft at [opencode@microsoft.com][msoss_contact]. That mailbox has no visibility of this fork.
